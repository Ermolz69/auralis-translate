# Experimental v6 target-bound response schema

Status: candidate contract for `CTX-02` and `REG-003`, 29 September 2026. This does not replace or rewrite the [v5 context profile](chinese-context-profile-v5.md). The [frozen comparison](../../eval/experiments/2026-09-29-v6-slot-schema-long-plan.md) tests a single new candidate against the archived v5 long-file failure.

The original v5 run correctly rejected a response whose `segment_id` named the following context cue. A small paired schema screen accepted both arms in four new calls and did not establish a reliability gain. V6 therefore remains experimental. Its only intended request difference is the `response_format` JSON Schema: `segment_id` and `line_index` are `const` values equal to the one declared target slot. The rendered user prompt, Chinese source, scene context, approved terms, protected money facts, model file, decoding settings, response reserve, tokenizer preflight and strict post-response validation remain the same. The schema is a generation constraint, never trusted evidence that the returned text belongs to the correct Chinese line.

The v6 manifest has its own `prompt_version=6` and SHA-256 bound to both the unchanged v5 prompt renderer and the new target-schema source. V5 manifests and saved runs retain their original identities and output. A v6 run cannot resume a v5 run, and a changed profile cannot resume v6. The CLI's existing `translate-v5-scene` command accepts either contextual profile while this experimental command surface remains; run identity uses the manifest bytes, not the command name. Source and scene-map bytes remain immutable, and no checkpoint is saved unless the whole provider response passes the same exact slot, text and protected-fact checks as v5.

This candidate still sends one slot per request and uses the same deterministic source-context trimming. It does not complete multi-target token sizing, scene-quality review, natural long-file gates or the audio handoff. A completed synthetic file would prove only structural delivery and recovery for this exact profile. Human source-aware review and independent sources are required before any translation-quality or release claim.
