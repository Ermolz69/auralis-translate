# Provisional target terminology development contract v1

Date: 3 October 2026. REG-061, scoped prerequisite of EVAL-04 and CTX-03.
This is an experimental request transformer, not a product profile or a human
approved glossary. Existing v8 manifests, prompt bytes and durable runs remain
unchanged. ASUS usage provenance remains in the rejected REG-058 term screen.

Select each provisional term from the declared target's original Chinese text
only. Neighboring source context never activates a hint. Keep all target/context
fields, protected facts and approved_terms unchanged. With no eligible target
usage, serialize exactly the baseline request, byte for byte. A request containing
both terms receives only the individually admitted terms, bound to its slot.

Clause-level conservative admission excludes negated, quoted and naming/translation
mentions. Ambiguous CPU compounds also produce explicit needs_review. Preserve
the baseline in these cases; this lexical screen does not claim to parse arbitrary
Chinese scope or double negation. Comparisons keep both referents and all source
bytes. Numbers and money are never edited to make a term fit. No cue-specific
substitutions or complete reference translations enter prompts.

The versioned policy, implementation, exact request, source, model, runtime and
baseline manifest hashes define development resume identity. Changed identity
cannot reuse an accepted observation. The experiment itself cannot resume or retry:
one retained attempt only. Rendered tokenizer counts include the selected hint,
256 output tokens and 64 safety tokens within 2,048; an oversized target is rejected.

All experiment responses are raw observations with zero durable checkpoints and
zero published subtitle results. Structure validation precedes candidate extraction;
semantic errors and uncertainty stay in separate AI review evidence. Human review
remains missing. Only a complete passing paired screen may justify a separately
versioned product candidate and one bounded 268-cue development run. A failed
screen leaves v8 unchanged and forbids that full-file run. Neither outcome passes
G3–G5, RELEASE-05, any audio gate or the full Goal.
