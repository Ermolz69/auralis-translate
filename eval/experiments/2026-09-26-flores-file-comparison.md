```powershell
$env:PATH = 'E:\Anything\Projects\Commercial\auralis-translate\.cache\runtime\cudart;' + $env:PATH

```

Use paths to an already installed local runtime/model. This task does not download or publish weights. GPU layers default to zero; requesting GPU offload here records only this test configuration and does not add a supported GPU installation package.

`task eval:file:checks` separately verifies that the harness rejects changed protected bytes/timing, reordered or missing candidate IDs, and source lines that would create extra fixture cues. All three checks passed. `task lint` and `task test` also passed after the runtime archive-verification additions.
