# Authored Chinese context contrast corpus v1

Status: `DATA-02` development corpus accepted for structural experiments on
28 September 2026. It is **not** a human-reviewed translation benchmark or a
release holdout.

## Scope and provenance

The original authored seed table
[`context-case-seeds-v1.mjs`](../corpora/context-case-seeds-v1.mjs) expands
deterministically into
[`context-contrasts-v1.json`](../corpora/context-contrasts-v1.json).
The generated file has SHA-256
`a7b1e8fc1617121db7637f925b913ecafb1a2917dedbb17ee6424c2137a6ba66`.
All source lines are newly authored development examples. Russian references,
expected facts and prohibited facts are AI proposals; provenance is
`ai_authored_unreviewed`. No external media, independent bilingual review or
natural-scene performance is represented. The corpus must never be promoted
to a sealed holdout or treated as human gold.

There are 60 unique Chinese targets: 12 each for pronoun reference, split
negation, names/terms, money/facts and idiom/irony. Each target has four stable
scenario identities: isolated, relevant source context, unrelated source
context and a source counterfactual. The relevant and counterfactual cases
state different expected/prohibited facts. Some negative controls deliberately
retain the same Russian surface form when context changes a referent without
requiring it to be named in a subtitle; fact review must consider the source.

The seed rows contain, in order, ID, category, Chinese target, isolated Russian
proposal and fact, relevant Chinese context/Russian proposal/fact,
counterfactual Chinese context/Russian proposal/fact, and whether the isolated
target is ambiguous. A `|` separates a context line before the target from
an optional line after it. Unrelated lines are cycled from a separate authored
pool. References and facts are stored only in the evaluation corpus. The
`modelInputForScenario` projection exposes the target, before/after Chinese
context and scenario ID; it excludes reference and scoring fields. Experiments
must use that projection or an equivalent source-only adapter, never serialize
the full case into a model request.

## Acceptance and limits

`task eval:context:cases:build` regenerated the frozen JSON. Then
`task eval:context:cases:check` passed four semantic/schema tests and verified
the generated bytes, unique IDs/targets, balance, 240 scenario IDs, distinct
contrasts and reference exclusion from model input. These are corpus integrity
checks. They do not establish that every Russian proposal is idiomatic, that
an interpretation is the only valid one, or that any model improves with
context. A bilingual source-aware review is required before reporting
semantic accuracy. The paired model comparison, bounded repetitions, raw
outputs and failures belong to `CTX-04`, after `CTX-02` and `CTX-03`.

This corpus is a development set. Natural subtitle scenes and independent
holdout sources remain separate under `DATA-03` and `DATA-04`; no example here
is eligible for those splits. Changes to a seed or expected fact require a
new corpus version and recorded source/contract reason so earlier experiments
remain reproducible.
