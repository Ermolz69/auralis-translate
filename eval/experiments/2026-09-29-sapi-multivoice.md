Status: partial engineering evidence for `VOICE-01` and `VOICE-02`, 29 September 2026. Auralis isolated branch `feat/real-tts-pilot` local commits `3000d6a`, `1cf3cea`, `e537d31` and `106ecdf`. The branch is not an upstream release. The frozen plans, both runtime outcomes and source checks are in Auralis `docs/voice/005-sapi-multivoice-plan.md` through `008-pwsh-voice-map-result.md`. The [raw measurement snapshot](../reports/2026-09-29-sapi-multivoice-pwsh-probe.json) matches the Auralis committed evidence by SHA-256 `c229e64c9619548ea4c7174b17b17e1a7a7c1ea625eead2c1b732cdf591bcc45`.

The reviewed-script handoff now carries an ordered voice ID for every cue. Domain validation rejects omitted, extra, reordered and unavailable IDs, and the SAPI adapter selects the declared voice per cue. `task voice:handoff:check`, `task voice:tts:check`, `task voice:handoff:lint`, `task voice:tts:lint`, `task rs:fmt` and `task docs:check` passed for the implementation. This validates mapping and Rust contracts, not reviewed speech or user-audible distinction.

The first frozen real `task voice:tts:multivoice:probe` failed after 3.41 seconds: child Windows PowerShell could not select the second requested Russian voice. The private run directory was empty, proving no partial WAV publication at this boundary. Read-only child inventory listed `Microsoft Irina Desktop` and English `Microsoft Zira Desktop` for `powershell.exe`; the separate PowerShell 7.6.5 child additionally listed Russian `Microsoft Pavel`. The candidate changed only to an absolute, SHA-256-verified PowerShell 7 runtime from the local Codex dependencies. `task voice:tts:multivoice:pwsh:probe` passed the real phase in 3.73 seconds, producing two distinct WAVs from the **same authored Russian line**. This local runtime is not a shippable Auralis dependency or clean-install evidence.

`task voice:tts:multivoice:inspect` used Auralis-pinned FFmpeg/FFprobe to decode both WAVs. Irina Desktop: 3,564 ms, 157,224 bytes, SHA-256 `798763e6c70c455cabe9e21d55b74350a1c08ce8671ba468cde13cad48db3d80`; Pavel: 3,169 ms, 139,792 bytes, SHA-256 `51915592e334218d9cbe8851abe71befc214a87d1834273493576a757c237af1`. Both are mono 22,050 Hz 16-bit PCM and have zero clipped samples. Cue windows are 2,400 and 1,900 ms, so the overruns are 1,164 and 1,269 ms. Fit **failed**. The first inspection attempt failed because restricted process access denied FFmpeg spawn (`EPERM`); the permitted retry completed without regenerating the WAVs.

No human listened to or rated these voices; no natural video or final media was played. The synthetic authored line has no independently reviewed Chinese translation. Voice pronunciation, semantic adaptation, per-speaker approval, resource leasing, media sync and A1–A6 remain open. The earlier failed-fit one-voice baseline, synthetic MP4 and cancellation result are preserved separately. No audio is embedded in the public report because redistribution rights for these synthesized voices remain unresolved.
