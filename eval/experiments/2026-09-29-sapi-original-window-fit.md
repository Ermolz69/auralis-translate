# Real two-voice SAPI original-window tempo screen

Status: measured private technical `VOICE-03` candidate on 29 September
2026, with Auralis isolated branch `feat/real-tts-pilot` commits `b0feb91`
(predeclared plan) and `0afa465` (retained result). Neither commit changes the
main Auralis checkout, its Translate submodule pin or the earlier failed-fit
report. The two input WAVs were already generated by real Windows SAPI with
Microsoft Irina Desktop and Microsoft Pavel. They say the same authored
Russian control sentence; this is not a reviewed translation.

The experiment used the [pinned source SAPI report](../reports/2026-09-29-sapi-multivoice-pwsh-probe.json),
SHA-256 `c229e64c9619548ea4c7174b17b17e1a7a7c1ea625eead2c1b732cdf591bcc45`.
Original WAV durations 3,564 and 3,169 ms overran their original cue windows
of 2,400 and 1,900 ms. FFmpeg `atempo` applied only the predeclared factor
`original_duration / (window - 75 ms)` to each unchanged spoken line. No
samples were deliberately cut, no cue start moved, no new TTS or model request
occurred. The resulting measured WAV durations were:

| Voice | Factor | Fitted duration | Original window |
| --- | ---: | ---: | ---: |
| Microsoft Irina Desktop | 1.533× | 2,316 ms | 2,400 ms |
| Microsoft Pavel | 1.736× | 1,812 ms | 1,900 ms |

In Auralis, `task voice:media:original-window:probe` passed the media-tool
identity check, script syntax, input hashes, fit, mux and full stream decode.
The five-second H.264/AAC MP4 SHA-256 is
`21167f4b9fc70afafeed598c183813d803a05840ede7d94385695fd91cca8fd1`.
Both speech regions had nonzero decoded RMS, the sampled seam was silent,
and no decoded PCM sample clipped. `task voice:media:original-window:play`
opened that exact MP4 and FFplay completed. `task
voice:media:original-window:check` and `task check:docs` passed. The copied
[machine report](../reports/2026-09-29-sapi-original-window-fit-report.json)
and [playback record](../reports/2026-09-29-sapi-original-window-fit-playback.json)
have SHA-256 `8c9c6fa877353a6789c59467dfe7d38f2e60c60a288a911b7d6875f848aec0d6`
and `34415cf27baf9536ddb3d93906dc50696e0f7e0f142d1333d4eb101fface7325`.
They contain metadata only; private WAV and MP4 bytes remain in the Auralis
voice worktree.

The factors are large. FFplay process completion and nonzero RMS cannot
establish intelligibility, pronunciation, naturalness or speaker suitability.
No person listened, no 10–20-minute licensed scene or reviewed script was
used, and this standalone tool is not a production mixer or accepted fit
policy. A1–A6 and `VOICE-01`–`VOICE-07` remain open. Independent listening,
script review, rights and a natural full-scene test are needed before audio
acceptance. `task eval:voice:original-window:check` pins the public metadata
without publishing speech bytes.
